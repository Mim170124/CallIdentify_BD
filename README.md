# CallIdentify_BD

## Smart Caller ID and Unknown Number Identification System

### Project Description
CallIdentify_BD is a Java-based Android application designed to identify unknown incoming phone numbers.

### Main Features
- Add phone numbers and names
- Search unknown numbers
- Identify available caller information using an API
- Detect unknown callers
- Display caller names during incoming calls

### Technologies Used
- Java
- Android Studio
- SQLite Database
- Online API

### Project Objective
To help users identify unknown callers and make phone communication safer.
